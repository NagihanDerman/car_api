## 🚗 Car API – API de véhicules avec Express.js

Ce projet est une application API RESTful simple, développée avec Node.js et Express.js. Il permet de gérer des données de véhicules en utilisant les méthodes HTTP de base comme `GET`, `POST`, `PATCH`, et `DELETE`. Il utilise également `nodemon` et des middlewares personnalisés du framework Express.

## 🚀 Fonctionnalités

- API RESTful construite avec Express.js
- Support des middlewares (ex. : logger, validation d’ID)
- Middleware de journalisation simple
- Opérations CRUD complètes pour les voitures
- Redémarrage automatique du serveur avec `nodemon` pour le développement

## 🛠️ Technologies Utilisées

- [Node.js](https://nodejs.org/)
- [Express.js](https://expressjs.com/)
- [nodemon](https://www.npmjs.com/package/nodemon)

## 🧪 API Endpoints

- `GET /api/v1/cars` → Get all cars  
- `GET /api/v1/cars/:id` → Get a car by ID  
- `POST /api/v1/cars` → Create a new car  
- `PATCH /api/v1/cars/:id` → Update a car  
- `DELETE /api/v1/cars/:id` → Delete a car  



### 🚗 Car API – Vehicle API with Express.js

This project is a simple RESTful API application built using Node.js and Express.js. It manages car data and supports basic HTTP methods like `GET`, `POST`, `PATCH`, and `DELETE`. The project also includes usage of `nodemon` and custom middleware features from the Express ecosystem.

## 🚀 Features

- RESTful API built with Express.js
- Middleware support (e.g., logger and ID validation)
